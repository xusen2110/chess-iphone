# Шахматный тренер — версия для браузера и айфона

Игра открывается по ссылке: https://xusen2110.github.io/chess-iphone/

На айфоне: откройте ссылку в Safari → «Поделиться» → «На экран „Домой“». Появится значок, игра будет запускаться на весь экран.

Файл `index.html` — та же игра, что в приложениях для Android и Windows (репозиторий `chess-kom-trener`).

Шахматные фигуры: набор Chessnut, автор Alexis Luengas, лицензия Apache 2.0 (https://github.com/LexLuengas/chessnut-pieces); цвета изменены.

Анализ ходов: Stockfish 10 (https://stockfishchess.org) в сборке stockfish.js (https://github.com/nmrugg/stockfish.js), лицензия GNU GPL v3. Исходный код Stockfish доступен по этим ссылкам; приложение, в которое он встроен, распространяется на условиях GPL v3.
